# Tyguri Portfolio

A picture-free first layout pass for the five-page portfolio. It contains text-only navigation, page structure and clearly marked slots for artwork and links. No mockup images or visual assets are embedded.

## Pages

- `index.html` — Home, introduction, facts, social destinations, Animation and Pictures feature panels
- `pages/animation.html` — Intro, 3M+ statistic, three content categories, separate FNAF video section, applications
- `pages/pictures.html` — Intro, 500K+ statistic, platforms, five distinct artwork slots, commission section, applications
- `pages/clothing.html` — Clothing intro, applications, independent project area
- `pages/edits.html` — Edits intro and independent project area

## Editing

- Change page words in the matching HTML file.
- Change spacing, typography, borders, and responsive layout in `styles/site.css`.
- Replace each labeled `media-slot` with its own image or video element when original assets are ready.
- Replace “link to add” labels only after the real destination URLs are known.
- The shared navigation appears on every page and keeps the requested order.

The initial files in the working folder were reference mockups, so this layout intentionally leaves all artwork slots empty. It uses no emotes, logos, decorative graphics, or mockup backgrounds.

## Run locally

Open `index.html` in a browser. The site uses relative links and does not require a build step.
